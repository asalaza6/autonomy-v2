# Archived PRD Specs

Completed PRD spec JSON files can be moved here to keep the active `prds/` directory focused on current work.

The runtime sync only imports active JSON files from `prompts/autonomous/v2/specs/prds/` and ignores files under `archived/`.
Queued PRD specs under `prompts/autonomous/v2/specs/prds/queue/` are also ignored until promoted on the next sync.
